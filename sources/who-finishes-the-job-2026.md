## What this document is
A mining study of merged AI-agent pull requests in the AIDev-pop dataset, following each merge for 30 days to find a later "fix" PR, comparing the rate with human merges in the same repositories, and attributing who authored the fixes (PR opener and commit level). Four RQs: (1) how often merged agent PRs are followed by a fix vs human merges; (2) who opens the fix PRs; (3) how agent-authored the fix PRs' commits are; (4) which merge-time signals distinguish agent merges that later need a fix.

## Full notes

### Data
- Source corpus: AIDev (Li et al. 2025/2026), AIDev-pop = repositories with more than 500 stars as of 22 Jun 2025, merged PRs only.
- Agent slice: 6,774 merged agent PRs across 891 repositories: OpenAI Codex 2,834; Devin 1,813; GitHub Copilot 1,428; Cursor 569; Claude Code 130. Period 24 Dec 2024 to 30 Jul 2025.
- Human slice: 5,044 merged human PRs from AIDev's human_pull_request table, same star and merge-only filters, 1 Jan to 28 Jun 2025. Commits, diffs, reviews and comments re-fetched via the GitHub REST API. Selection is by filter only (same repositories, merged), not by matching on size, task or type. "Contemporaneous" is operationalised by cutting both cohorts at the human end date (28 Jun 2025) for the cross-cohort comparison.
- Repository coverage: 218 repositories contain both cohorts (strata for the Mantel-Haenszel estimate).
- 30-day observation rule: merges within 30 days of dataset end are dropped, leaving 4,505 agent PRs (Codex 2,049; Devin 1,519; Copilot 721; Cursor 153; Claude Code 63; 67 of 130 Claude Code PRs dropped). Shared-window comparison: 2,012 agent vs 4,063 human merges.

### Method
- Candidate fix Q for merged P: (1) merged in same repository strictly after P within 30 days; (2) classified as "fix" type by AIDev's task-type tag; (3) co-edits at least one file in P's net diff; (4) at least one co-edited file is non-boilerplate (lockfiles, changelogs, generated files excluded). Q may be from either cohort (agent or human).
- Verification: two annotators (first and second author) labelled 50 candidate agent pairs as Direct fix (Q fixes the specific change P introduced), Related touch, or Unrelated. Only Direct fix counts as verified. Binary agreement 45/50 (90%), kappa 0.77; three-way kappa 0.60.
- LLM judge (Claude Opus 4.8, temperature 0), binary Direct fix vs Non-fix, developed on the 45 agreed pairs, applied to 2,510 agent and 2,206 human candidate pairs. Re-validated on 50 new agent and 50 new human pairs by the second author: judge-human kappa 0.78 on agent pairs (three-way 0.46); Direct-fix precision 27/30 = 90% in each cohort, pooled 54/60 = 90% (Wilson 95% CI 80-95%). "Adjusted" rates scale verified rates by the pooled precision. 203 of 4,505 agent PRs carry a verified fix (189 judge-verified, 14 human-verified).
- Author classes: PR level (human, self-agent, other-agent including bots); commit level (agent, automation, human) by login patterns and message markers, extending Duma et al. (2026). Codex does not sign commits (fewer than 2% carry a marker), so Codex is excluded from commit-level shares.

### Results
- Candidate fix rate within 30 days: 22.9% of agent merges (n=1,032 of 4,505). Verified: 4.5% (n=203); adjusted 4.1%. Per agent verified (adjusted): Codex 5.5 (4.9); Cursor 5.2 (5.0); Devin 3.7 (3.4); Claude Code 3.2 (3.2, n=63); Copilot 3.5 (3.1).
- Shared window: verified 3.68% agent (74/2,012) vs 2.34% human (95/4,063); adjusted 3.34% vs 2.10%. Candidate 20.9% vs 14.7%.
- Mantel-Haenszel OR over 218 repositories: verified 1.62 (95% CI 1.10-2.39, p=0.015); candidate 1.41 (95% CI 1.19-1.68). MH risk ratio 1.59. Kaplan-Meier: curves separate from day 1; half of the 30-day incidence arrives in the first week in both cohorts; day-30 verified cumulative incidence 4.5% agent vs 2.6% human. No fix-size or time-to-fix distributions beyond this are reported.
- RQ2 (n=263 verified pairs on agent merges): self-agent 69.6%, human 27.4%, other agent 3.0%. Codex 59.2/38.4/2.4 (n=125); Devin 72.7/23.9/3.4 (n=88); Copilot 95.0/5.0/0 (n=40); Cursor 87.5/0/12.5 (n=8); Claude Code 0/50/50 (n=2). Human merges (n=110): 89.1% human, 10.9% agent.
- RQ3 (commits in verified fix PRs): 123 non-Codex agent fix PRs, average agent share 87.4% per PR, 76.4% of PRs all-agent; Copilot 86.6/70.0 (n=40), Devin 92.0/84.7 (n=59), Cursor 79.1/69.6 (n=23), Claude Code n=1. Human-opened fix PRs: 0.8% agent share (n=124, 554 commits). For comparison, all 3,940 non-Codex merged agent PRs: 78.8% average, 54.1% all-agent; human PRs 0.9% / 0.6%. Authors infer agents write fix PRs more fully than they write merges generally.
- RQ4: pooled merge-time signals nearly identical. Cliff delta, verified: time under review -0.221 (small), review items -0.239 (small), commits +0.013, churn +0.032 (negligible; p=0.75, 0.41). Within-repository conditional logistic model with repository fixed effect and PR size control (log non-boilerplate files shipped): tenfold commits OR 6.1 (p<0.001); review items OR 2.4 (p=0.022); churn OR 1.3 (p<0.001); time under review not significant (p=0.18).

### What "fix" means
A later PR that the AIDev task-type tag classes as fix type, merged within 30 days, touching a file P changed, and judged (human or LLM) to correct the specific change P introduced. It is a bug-fix style correction by PR typing, not a revert detector, not a refactor or follow-up feature. Severity, user impact, defect type and effort/time to fix are not measured. The authors say the rates are floors: cross-file fixes, fixes after 30 days and fixes inside non-fix-typed PRs are missed.

### Authors' limitations
Author-class counts measure who committed or marked a change, not who wrote it; Codex unsigned; agent-authored shares are lower bounds. Candidate linking by file co-location misses some fixes. Commit fetch capped at 30 per PR (under 2% affected). AIDev agent labels derive from commit-author patterns, so unmarked agent PRs may sit in the human table. Fixer identity captures authorship, not ownership via review. Population limited to five agents in >=500-star repositories. Verification reliable only at binary level. Per-cohort own-window rates are never compared because the shared cut-off leaves, for example, 4 observable Cursor merges and no verified Copilot fix.

### Authors' interpretation
"Agents largely finish their own job on both sides of the merge, but their merges need fixing modestly more often than human merges, with little visibility up front." Discussion argues merged agent PRs should be monitored beyond merge, review should include reading code, and that self-fixing mirrors human self-fixing but with an agent as the operational owner (raising questions on model deprecation and ownership policy).

## Tier & era grading
- Tier: B (structured observational, large-N repository mining, no randomisation, repository-stratified comparator, human-validated outcome labelling). Ceiling is B with caveats, not A: no counterfactual, unmatched human comparator, outcome labels from an LLM judge validated on small samples.
- Era: E3. All studied tools are autonomous PR agents (Codex, Copilot coding agent, Devin, Cursor, Claude Code) operating in 2025.
- Independence: the data is the AIDev-pop dataset, a corpus created by another group (Li et al., Queen's University). Any finding shares that dataset's provenance and attribution limitations (agent labels from commit-author patterns; unmarked agent PRs in the human table; AIDev task-type tags used to define "fix") with other AIDev-based studies; these must not be counted as independent corroboration of each other for triangulation. Authors are independent of the agent vendors. Funding: Australian Composites Manufacturing CRC (HPN003), no vendor money, no declared COI. Not Tier D. Note the LLM judge is an Anthropic model while Claude Code is one of the studied agents (n small, so impact negligible).
- Version note: v2 (24 Sep 2026) read; v1 not compared.

## Measured vs self-reported
All findings are measured (repository telemetry plus human/LLM labelling of PR pairs). No self-report. Delta findings: none. Outcome is a proxy (a later fix-type PR judged Direct fix), not a defect count; labelling is partly human, mostly LLM judged (90% precision, recall unmeasured).

## Can / cannot support - verdicts
- CAN support (medium confidence): in popular open-source repositories in H1 2025, merged agent PRs were followed by a verified Direct-fix PR within 30 days at somewhat higher odds than human merges in the same repositories (OR 1.62, CI 1.10-2.39), with low absolute rates (about 3-5%). Supports a quality-debt/rework direction for RQ3/RQ4/RQ5 and the "merge is not the end" point for T7 review. Supports the observation that agent follow-up fixes are mostly opened by the same agent (69.6%).
- CANNOT support: causal claims that agents produce worse code; severity or cost of rework; effects in private or mature enterprise codebases; per-agent rankings (Claude Code and Cursor n tiny); that humans have or have not "retained maintenance" (27.4% human-opened fixes is a count of PR openers, not responsibility); any productivity or time-saved claim; 'fix' rates beyond 30 days.
- Exec-brief use: only as one AIDev-based Tier B signal, flagged with shared-dataset provenance; not as an independent corroboration of other AIDev studies.

## Red flags / things the orchestrator should know
1. Controls on the 1.62x are limited. The RQ1 estimate is a Mantel-Haenszel OR stratified only by repository (218 repositories with both cohorts, 2,012 vs 4,063 merges in the shared window). There is no adjustment for PR size, task type, files changed, or complexity in RQ1. The size control (log non-boilerplate files) appears only in the RQ4 within-agent regression. The authors cite other work finding agent PRs are smaller, which would bias toward fewer fixes, but task mix may differ (agents get well-specified tasks; humans get harder ones, or the reverse). Direction of confounding is unknown. The CI lower bound is 1.10.
2. Shared window cut-off of 28 Jun 2025 shrinks the agent cohort to 2,012 of 4,505 observable; the headline OR rests on 74 agent and 95 human verified fixes. Small counts.
3. The human comparator is not selected by matching; human PRs include maintainers' large changes and routine merges. The judge was developed on agent pairs only; precision checked on both cohorts (27/30 each), but recall unmeasured, and differential recall between cohorts is untested.
4. 'Same agent fixes' depends on who re-invokes the agent. A human (maintainer) typically assigns an issue or comments on the agent's PR to trigger a fix, and a Copilot-style agent iterates on its own PRs by design; the paper only observes who opened the fix PR, not who decided it was needed or triggered it. 'Agents finish their own job' should therefore be read as 'the fix PR is opened under the agent identity', not autonomous maintenance. Human-opened fix share (27.4% overall, 38.4% for Codex) is non-trivial. Codex's unsigned commits mean agent attribution for its PRs is PR-level only and some 'human' fixes could be agent work and vice versa.
5. Human fixes of human merges (89.1%) may be inflated by unmarked agent PRs in the human table; the authors acknowledge this.
6. 'Fix' is narrow (fix-typed PR, shared-file, 30 days, Direct fix) and unweighted by severity; it undercounts rework. Not evidence on production stability.
7. Interpretation: both 'humans retain maintenance' and 'agents fix their own work' overreach. The data support: fix PRs on agent merges are mostly agent-opened, humans open about a quarter, and agent merges are fixed more often. Review burden implication is the authors' inference (RQ4 shows merge-time review signals do not predict fixes).
8. Preprint, authors are also annotators (first and second author), 50-pair validation samples.
9. Claude Code n=63 observable merges and 2 verified pairs: do not report Claude Code figures as findings.
10. Internal minor inconsistency: 263 verified pairs (RQ2) vs 203 PRs with verified fix (RQ1) and 123/124 fix PRs in RQ3 (pairs, PRs and fix PRs are different units); one P can have several Q.
